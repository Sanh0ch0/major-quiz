# 전공 퀴즈

경영학·회계학·재무관리를 휴대폰에서 풀어 나가는 퀴즈 웹 앱입니다. (https://sanh0ch0.github.io/major-quiz/)

- **경영학**은 장을 고르면 `[푼 문제 수 / 전체 문제 수]`로 이어서 풀립니다. 장 안의 문제를 순서대로 풀고, 그만두었다가 다시 들어오면 처음 안 푼 문제부터 이어집니다.
- **회계학·재무관리**는 장 → 단계(10문제) 순서로 풀고, 정답률에 따라 별 1~3개를 받습니다 (60% 이상 통과).
- 별과 풀이율로 과목 등급(새싹 → 브론즈 → 실버 → 골드 → 플래티넘 → 다이아 → 마스터)이 오르고, 맞힌 문제·별로 경험치와 레벨이 쌓입니다. 등급·칭호·배지는 한 화면에서 봅니다.
- 통계 화면에서 전체·과목별·장별 풀이율과 정답률, 최근 14일 학습량을 확인합니다. 장 색은 풀이율에 따라 옅은 회색에서 진한 주황으로 이어집니다.
- 틀린 문제는 간격 반복으로 '오늘의 복습'에 다시 나옵니다.
- 기록은 한 기기에서 GitHub 토큰(gist 권한)으로 연결하면 비공개 Gist로 자동 동기화되고, 다른 기기는 연결 링크로 이어집니다. 경영학에는 기출 2,938문제를 섞어 풀 수 있습니다.
- 설정의 '기록 가져오기 · 백업'에서 예전 '전공 기출 CBT'의 장별 푼 문제 수를 `1장 12/40` 형식으로 옮겨 넣거나, 현재 기록을 JSON으로 내보낼 수 있습니다.
- 문제 데이터(`data/m.bin`, `data/g.bin`)는 4자리·기출 비밀번호로 AES-256-GCM 암호화되어 있습니다.

## 문제 수정·추가 / 비밀번호 바꾸기

원본 문제 파일(`src/new/*.json`)은 저장소에 올리지 않습니다. 원본이 있는 곳에서:

```
pip install cryptography
python3 tools/build.py --password "비밀번호" --gc-password "기출 비밀번호"
```
