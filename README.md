# 전공 퀴즈

경영학·재무관리를 휴대폰에서 단계별로 풀어 나가는 퀴즈 웹 앱입니다.

- 과목마다 장 → 단계(10문제) 순서로 풀고, 정답률에 따라 별 1~3개를 받습니다 (60% 이상 통과).
- 별을 모으면 과목 등급(새싹 → 브론즈 → 실버 → 골드 → 플래티넘 → 다이아 → 마스터)이 오르고, 맞힌 문제·별로 경험치와 레벨이 쌓입니다.
- 틀린 문제는 간격 반복으로 '오늘의 복습'에 다시 나옵니다.
- 기록은 설정에서 GitHub 토큰(gist 권한)을 넣으면 비공개 Gist로 기기 간 동기화됩니다.
- 문제 데이터(`data/m.bin`)는 AES-256-GCM으로 암호화되어 있어 비밀번호 없이는 볼 수 없습니다.

## 문제 수정·추가 / 비밀번호 바꾸기

원본 문제 파일(`src/new/*.json`)은 저장소에 올리지 않습니다. 원본이 있는 곳에서:

```
pip install cryptography
python3 tools/build.py --password "비밀번호"
```
